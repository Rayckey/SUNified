# UR5: place an object in the drawer

The 14-stage SUN Program opens the top drawer, grasps the strawberry, places it
in the drawer and releases it. The insertion target uses the strawberry's
interaction frame, 3 cm above the drawer center, to account for the grasp offset.

Run `UR5-Table-Drawer-Stack` with the [MPC collector](../../../docs/UR5.md#run).
The task selects this program by default. Its remaining constraints reuse the
[drawer program](../manipulation-fr3-finray-drawer-stack/2026-04-01_14-56-05/program).
