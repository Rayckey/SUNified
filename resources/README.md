# Prepared resources

`learned_programs/` stores saved SUN Programs and provenance.
`experiment_definitions/` stores prior configurations, parameter/weight records
and generated launchers. `checkpoint_catalogs/` and `media/` index external
checkpoints and recordings. `robots/` supplies controller robot descriptions.

Task inputs, prompts, skills and current configs live in [assets](../assets/README.md).
New run output lives under [KUAFU_ARTIFACT_ROOT](../docs/PIPELINE.md).
