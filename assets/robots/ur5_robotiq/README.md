# UR5 with Robotiq 2F-85

Kuafu loads `ur5_robotiq.usd` for simulation and `ur5_controller.urdf` for MPC.
The USD includes the arm, gripper, collision meshes and materials in one file.
`source/` contains the local URDFs and meshes for rebuilding it.

`provenance.json` identifies the upstream revisions and source hashes.
`manifest.json` records the conversion, tool frame and output hashes.
Source licenses are listed in the [repository notices](../../../README.md#third-party-notices).

Follow the [UR5 guide](../../../docs/UR5.md) to run or rebuild the model.
