# Input assets

| Folder | Contents |
|---|---|
| [tasks](tasks/) | Task instructions and measurable objectives. |
| [prompts](prompts/) | Program formation and asset reconstruction prompts loaded by the code. |
| [skills](skills/) | Per-operator argument contracts and descriptions. |
| [configs](configs/) | Pipeline, learning and campaign configurations. |
| [recipes](recipes/) | Editable asset reconstruction proposals. |
| [objects](objects/) | Object geometry, articulation and textures. |
| [robots](robots/) | Simulation robot models. |

Save generated assets under a [run directory](../docs/PIPELINE.md). Licensing and
third-party attribution are listed on the [front page](../README.md#license).
